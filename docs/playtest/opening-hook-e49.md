# 冒頭の異変→選択→反応 — E49公開候補

Status: 2026-09-26公開・agentの動作確認済み / 人間の初見・再訪の採否待ち。

入口: [現行本編E50](https://quietbriony.github.io/hazama/?v=e50)（E49の冒頭本文を継承し、表紙タイトルを簡素化）

## 仮説

八観や世界の構造を先に説明するより、最初の一行が「消える」という小さな異変を見せ、
その声に応えるか伏せるかを選ばせる。選んだ直後に手元と世界が反応すれば、
初見にも「読んで選ぶことで世界が変わる」作品だと伝わりやすくなるはず。
これは読み味の仮説であり、面白さが検証済みという意味ではない。

## 変更した体験

- 零章: 消したはずの画面に『まだ、見ている？』が残る。触れる前に消え、首の後ろから声がする。
- 伏せる: 机の木目が一度だけ波打つ。実際に戻り道が5→4本となる選択なので、説明も「−1」に合わせた。
  浅い退避の共通処理は数値変更せず、零章だけ合う短い反応文を表示する。再訪の選択文も同じ消費を示す。
- 応える: Aの冒頭でデバイスが一度だけ震え、通知はない。月の二重像と、触れていない床の冷たさが
  構造/身体の分岐を先取りする。構造Bでは、なぞった線が残る。身体Bの足裏から世界が来る描写は維持。
- Aの初回だけ八観の名称8行を表示しない。再訪では同じ名称を表示し、入口の一行や震えの意味も
  周回用の本文変奏で変える。八観自体・別の降り方の解放条件・選択の行き先は維持。
- 英語試作の初回身体ルートは追加文を翻訳し、既存ルートに合わせて二人称に統一。
  tools-only音比較のA本文抜粋も本編の初回Aに同期したが、A/B/C/Dの音のルールは変更しない。

## 2026-09-26の整備

再訪の本文は変奏だけでなく原文も抽選する。そのため、cycle=10・A訪問11回などで
「応えの代わりに、耳を澄ます」の次に「『誰だ』と口にすると」が出る組み合わせを再現した。
cycle=1〜64・訪問=cycle+1の診断では5通り。Aの原文も「声に意識を向けた途端」に揃え、
発話/傾聴どちらからもつながるよう修正した。英訳と比較音ページの引用も同期した。
zero_holdの「伏せた画面に部屋が映る」変奏は木目のうねりへ変更し、後続の「指を離すと戻る」へつなげた。

本番の`applyCycle`・乱数関数・選択文の抽選部分をそのまま取り出した一時診断で、
cycle=0〜64 × 訪問1〜16の1,040通りを確認。傾聴の304通りで発話扱いの文がなく、
Aの全4候補とzero_holdの全3候補を確認した。初回Aは4段落で英訳が揃い、再訪Aには八観8行が残る。
同じ状態からの再表示は同じ本文になり、表示処理の前後で進行状態・元データ・選択肢は変わらない。
`hazama-check`は2 PASS / 0 FAIL。本文の整合に絞ったこの整備sessionではブラウザ再試遊はしていない。

公開HTMLはこの整備sessionの確認時点でE48のCSS/JS/SW参照。E49のversionは未公開候補のまま維持し、

## 人に渡すときに見る点

初見者には作品の設定や正解を先に説明しない。最初の3分で、何が起きたと思ったか、
声に応える/伏せるのどちらを選びたくなったか、選んだ結果を感じたかを聞く。
Aの構造/身体で違いが想像できたか、「戻り道−1」が予期したコストだったかも確認する。
別の初見者には反対の道を強制しない。再訪した人には、八観の名前が発見か説明の負担か、
同じ場面の意味が変わったかを聞く。止めた場所と理由も記録する。

5〜10人の初見、実iPhone/Safari、標準文字送りの体感、音の間合い、英語話者の自然さは未判定。
これらを確認するまで「Steamで売れる」「ノベルとして面白い」は合格にしない。
