# Steamに向けた体験版候補 — E41

2026-09-05。対象は現在の没入版単一ビルド。旧Gate Runの計画書ではなく、この文書を今回の初見テストの入口にする。

この文書は実施側向け。参加者には[短い日本語案内](invite-ja.md)を渡す。
最初の依頼から返答の扱いまでは[最初の試遊ラウンド](first-round.md)を使う。

## いま確かめたいこと

「読む・選ぶ・景色が変わる」という体験を、説明を受けていない人が面白いと思うか。
Steamで販売可能な完成品、Steamに提出するビルド、売上の見込みを検証済みという意味ではない。
今回の成果は、既存のWeb版で試せる体験版候補と、その評価手順。

E41では次を整えた。

- 入口で、読むこと・記憶・道と結末の関係を短く伝える。
- 既定の文字演出は保ち、初見でも「全文を表示」で自分のペースに戻せる。本文を出すだけでは選択・採点しない。
- 本文の上に現在の深度を置く。全文表示で読んでいる位置を末尾へ飛ばさない。
- 結末で降りた道を振り返る。Ω到達／届く認識を持ちながら帰る／認識未達で帰る、を区別する。
- 詳細数値は「降下と記憶の記録」に畳み、ここで一度終えてよいことを伝える。既存の再降下・忘却・共有は保つ。
- 実ブラウザでの記録開閉の検証を受け、結末では本文の揺れを止める。道中の演出は保つ。

E42では「読む・聴く設定」を追加。文字サイズ（本文・選択肢・説明文）、自動全文表示、
音のオン/オフと音量を表紙・道中から調整できる。設定はページ内だけで、再読み込みで戻る。
初見テストではこれらを自由に使ってよい。設定が必要だった理由と、操作に迷ったかも聞く。
設定の使いやすさを検証しても、面白さ・Steam向け配布の完成とは扱わない。

E43は初回の身体の道を対象に英語試作を追加。日本語の自由な初見評価は本手順を続ける。
英語話者の翻訳対象を指定したテストは[English trial](english-trial-e43.md)で別に記録し、混同しない。

本文72ノード、分岐ルール、認識や抗いの数値、保存形式は変更していない。
独立した体験版モード、追加の保存キー、解析送信、外部依存、実行時AIは追加していない。

## 長さは、まだ「目標」

10〜15分で魅力を判断できる体験を目指す。ただし、現時点で一律「所要10〜15分」と宣伝しない。

原文の文字数と現行の文字表示式から、初回の最短前進経路を机上集計した値：

- 構造の道：zero→A→B〜Z→Omega→reborn、29ノード・6,476文字。文字演出の待ち約11.0分。
- 身体の道：zero→A→身体8ノード→Z→Omega→reborn、13ノード・3,065文字。文字演出の待ち約4.6分。

これはプレイ時間の実測ではない。文字送り・行間待ち・各画面の基本待ちだけの概算で、
読む速さ、選択の迷い、エコー門、寄り道、終端の文章、全文表示の使用により変わる。
短い身体ルートを、時間合わせのためだけに水増ししない。

## 初見テスト（人間の判断が必要）

まず5〜10人を目安に、普段ノベル／探索／ホラーを遊ぶ人と、遊ばない人を含める。
これは販売予測用の標本ではなく、混乱や離脱理由を見つけるための小さなテスト。
人の募集・連絡・外部送信は未実施。相手の了承なしに録画や回答収集をしない。

プレイ前に攻略方法や「正しい選択」は教えない。最初の道も本人に選んでもらう。
初回の記憶がないブラウザプロフィールで開始し、既存の個人データを消さない。
15分を目安に遊んでもらうが、途中で止めてもよい。止めた場所と理由も大切な結果。
全文表示・音の切替は自由。後から経路を固定した比較テストをする場合は、初見結果と分ける。

プレイ後に聞くこと：

1. 何をする作品だと受け取った？ 自分の選択で何が変わったと思う？
2. 続けたくなった場面と、止めたくなった場面はどこ？
3. 「全文を表示」を使った？ 文字演出は雰囲気になった、それとも待ちになった？
4. 結末は納得できた？ 自分で帰ったのか、届かなかったのか、区別できた？
5. 説明や依頼がなくても、別の道をもう一度試したい？ その理由は？

## 次の判断

「何が変わるか分からない」「終わりが分からない」が複数人から出るなら、本文量より先にその箇所を直す。
理解できても続けたい理由が弱いなら、読みの仕組みや物語の山場を見直す。見た目だけで販売判断をしない。
好反応が得られてから、有料版の範囲・価格仮説・PC配布方式を決める。
Windows向け配布、設定の永続化方針（保存契約の事前確認が必要）、インストール・更新・端末検証、
アセットの権利とAI利用の申告準備は残る。E42のページ内設定は完成版の全設定を代替しない。
