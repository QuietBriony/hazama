# Hazama 試遊のお願い

文章を読み、選びながら進む、制作途中のブラウザ作品です。
よければ少し遊んで、受け取ったことを教えてください。好意的な感想でなくても大丈夫です。

[Hazamaを開く](https://quietbriony.github.io/hazama/)

## 遊ぶ前に

- スマホでもPCでも、そのままブラウザで開けます。インストールは不要です。
- 日本語のまま「沈む」で開始し、道は自分で選んでください。攻略方法を探す必要はありません。
- 今回は15分ほどを試遊の区切りの目安にします。作品全体の所要時間ではありません。
  途中で止めても、結末まで進まなくても大丈夫です。
- 光の明滅と音があります。無理せず中断してください。
  「読む・聴く設定」で文字サイズ・全文表示・音を変更できます。音は開始前にもオフにできます。
  「読書優先」で文字をくっきり表示し、背景の明滅・揺れを抑えられます。OSの視覚効果軽減も使えます。
- 以前に遊んだことがある場合は、後でそのことを教えてください。試遊のために記憶を消す必要はありません。

## 遊び終えてから

<details>
<summary>感想の返し方を開く（プレイ後で大丈夫です）</summary>

この案内を送った人へ、次の3点を短く返してください。分からなかったことも、そのままで大丈夫です。

1. 何をする作品だと受け取りましたか？ 自分で選んだことで、何が変わったと思いますか？
2. 続けたい、または止めたいと思った場面はありましたか？ 最後に止めた場所と理由も教えてください。
3. 依頼がなくても、もう一度遊びたいと思いますか？ その理由は？

余裕があれば、次も一行で添えてください。

```text
初めて／以前も遊んだ：
スマホ／PC・ブラウザ・おおよそのプレイ時間：
音のオン／オフ、文字サイズや全文表示を変えたか：
操作で困った場所（あれば）：
```

氏名・連絡先・保存データは不要です。共有してよい範囲だけでかまいません。
スクリーンショットは任意です。送る場合は、通知など個人情報が写っていないか確認してください。
この案内には回答の送信フォームはありません。公開レビューの投稿もお願いしていません。

</details>
