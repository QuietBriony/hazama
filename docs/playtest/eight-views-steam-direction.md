# 八観を「設定」から「読む行為」へ — Steam方向の設計メモ

2026-09-20 / ユーザーの「八観設定今最適？ 空・仏教哲学・密教の公開ネタ？」への検討。
**結論: 最適とは言えない。八観は創作上の骨組みとして残し、初見に要求する知識は減らす。**
仏教的な題材を増やせば売れるという証拠はない。以下は商品方向の仮説であり、需要検証済みではない。

## 現物から見つかったこと

- 原典09の市場向け版は「空観」と「Void観」を別に数える。原典10の曼荼羅版は
  Void（空）と円観を含む。原典は別の用途/版であり、どちらかを誤りとして改変しない。
- 現在の入口Aと`UCM_AXES`は体・波・思・財・創・観察者・空・円。
  生成の第9軸「層」はその上の観測層であり、第9の観ではない。
- 流れの`S_reso`だけ市場向け版の8名称になっていた。今回ここを入口/生成側と一致させる。
  スキーマ、選択肢、認識値、分岐、原典資料は変えない。
- 原典10はVoidを仏教の空とは区別している。八観はHazama/UCM固有の創作枠組みであって、
  八正道や伝統仏教の標準的な8分類と同一ではない。
- 既に身体ルートの煩悩、再訪、観測層、二極終端という素材がある。増築より、選択への応答を磨く余地が大きい。
- 認識点の蓄積を「悟りの正解」「人間の優劣」にしてはいけない。浮上も有効な結末として保つ。

## 推奨するゲーム内の使い分け（次の制作仮説）

名称を8個並べて暗記させるより、先に作用を経験させる。8本の新ルートや8個のHUDは追加しない。

| 八観（内部の骨組み） | プレイヤーがすること | Hazamaで確かめる変化 |
|---|---|---|
| 体 | 重さ・温度・手触りを受けとる | 説明が足りなくても身体の道を選べる |
| 波 | 気配と間を聴く | 音が操作に応じ、同じ刺激への反応が少し落ち着く |
| 思 | 離れた断片を照らす | エコーや再訪で、以前見た構造がつながる |
| 財 | 何を価値として残すか選ぶ | 「お金」の説明でなく、戻り道や痕跡を手放す重みが分かる |
| 創 | 既知の断片を別の順で受けとる | 変奏が文章量の水増しでなく新しい意味になる |
| 観察者 | 誰が見ているのかを疑う | 私の位置が変わり、以前の声の意味が反転する |
| 空 | 意味や私を一つに固定しない | 消滅や無価値と混同せず、関係が変われば読みも変わる |
| 円 | 戻って差分を見つける | 単なるリセットでなく、次周の既視感が体験になる |

これは教義の8分類ではなく、作品内の動詞への翻訳案。「財→価値」等の全面改名、
全ルート改稿、認識/保存の新ルールはまだ実装しない。今回の確定変更は名称整合と音の接続だけ。

## 公開資料から取るもの／取らないもの

### 空・縁起

龍樹の空の議論は、物がそれ自身だけで成り立つ固有性への批判と関係する。
「何も存在しない」「死ねば正解」「万物は同じ神経回路」という短絡にはしない。
学説には解釈の幅もある。[Stanford Encyclopedia of Philosophy: Nāgārjuna](https://plato.stanford.edu/entries/nagarjuna/)
を概念の確認資料とし、その文章や現代訳をゲーム本文へ転載しない。

制作案: B→C→Bで同じ継ぎ目を見るが、直前の経験によって意味が変わる。
対象だけでなく、対象と見る者の関係を読む。これはHazamaの創作的翻訳で、教義を再現した証明ではない。

### 真言密教・三密・曼荼羅

[高野山真言宗・金剛峯寺の公式説明](https://www.koyasan.or.jp/shingonshu/)は、
身・口・意のはたらき、実践、仏と行者の感応を説明している。
密教を「呪文を増やすホラー装飾」としてだけ扱わない。

制作案: 指で選ぶ／音が応える／文章の意味が変わる、という三つの媒体を同じ場面で対応させる。
これは三密に着想を得たゲーム設計であり、正式な修法・灌頂・宗教上の効験ではない。
実在の真言・梵字・尊像を無作為なパスワードや敵素材にせず、必要になれば個別に出典・文脈・権利を確認する。
曼荼羅は今の独自canvasを活かし、伝統図像の画像を持ち込まない。

### 公開されていることと再利用できることを区別

古い思想や一般的な概念の参照と、現代の翻訳・解説・写真・図版・読経録音の複製は別。
個別素材は権利を確認する。今回は公開資料を読み、独自の設計仮説に留める。
[文化庁「他人の著作物を利用したい場合など」](https://www.bunka.go.jp/seisaku/chosakuken/seidokaisetsu/chosakukensha_fumei/)
と[文化庁・著作物の利用形態](https://www.bunka.go.jp/chosakuken/keiyaku_manual/1_1_1.html)を参照。

## Steamで伝える核

候補: **「読んだはずの世界が、あなたの読み方を覚えている。」**
英語候補: *The world remembers how you read it.*
読む・選ぶ・戻るうちに見え方が変わる、短い不穏な物語体験として伝える。
「仏教の教養がないと遊べない」「ハエの脳が意識を獲得した」とは売り込まない。

[The Exit 8の公式ストア](https://store.steampowered.com/app/2653790/The_Exit_8/?l=english)は
観察して出口へ進む行為を、[The Cosmic Wheel Sisterhoodの公式ストア](https://store.steampowered.com/app/1340480/The_Cosmic_Wheel_Sisterhood/?l=english)は
カードを作り選択で物語へ影響する行為を前面に出す。これを踏まえ、Hazamaも哲学の説明より
「何をして何が変わるか」を先に見せる、というのが今回の推論。
両作の成功要因やHazamaの売上を立証するものではなく、レビュー数を販売数に換算しない。

## 次の採否ゲート

既存HZ-BL-018の初見5〜10人テストで、小さな比較を行う。アンケート/外部募集の送信はまだ行わない。

3. 回路on/offを音量固定で比べ、「音に気を取られた」「沈めた」「疲れた」を分けて聞く。
4. 日本語と英語で「空=無価値」「Ω=唯一の正解」と誤読されないか。

E46の機械検証でこれらを合格にしない。設定追加、全編英訳、Steam提出・価格・販売判断は別の作業。
