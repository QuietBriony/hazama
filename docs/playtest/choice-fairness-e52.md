# E52候補 — 選択肢を読み終えてから決められるか

2026-09-27。人間の初見テストではなく、Codexが既存PagesのE51を隔離タブで通した操作・画面確認と、ローカルE52候補の再確認。
`全文を表示`を多用したため、自然な読書時間や面白さの実測ではない。

## 通し試遊で見えたこと

1. 表紙→零章で端末の異変に入り、応答せず伏せる→深度A→身体の道を選べた。伏せると戻り道が1本減り、分岐結果は画面で確認できた。
2. 身体の道をB→D→F→J→N→S→V→Y→Zと進め、Zの記憶の問いで実際に見た断片を選ぶと認識が2増えた。Ω→零章（再）→浮上まで操作できた。
3. 零章・A・道中・記憶の問い・再降下の選択で、先頭だけが後続より早く有効になった。後の候補を読む前に押せるため、初見の意思決定を演出が偏らせる。これは操作から確認できた問題。
4. 身体の道では「ただ沈む」系の選択が続いた。能動感が弱まる可能性はあるが、面白さの判定は人間に聞くまで保留。Ωに着いても核に届かず浮上する意味が伝わるかも同様に保留。

## E52候補で直したこと

- 通常分岐・記憶の問い・終端の二択で、段階的な出現は残し、最後の候補のフェードが終わるまで全候補を無効にする。その後、押せる候補だけ同時に有効化する。鍵付き・周回前の扉は従来どおり押せない。
- 最初の押せる候補へのキーボード／スクリーンリーダー用フォーカス移動も、全候補が揃った時点に合わせる。画面交代後の古いタイマーは解放しない。
- 原文、分岐先、進行値、保存形式、音、PWAの対象範囲は変えない。

## agent確認と次の人間テスト

- 既存E51を上記の経路で通し、E52ローカルでは390×844の零章→伏せる→A→身体Bを再試遊。Aの二択は同時に有効になり、後から現れる身体の道を選べた。さらに320×568のBを目視し、横はみ出しなし。ブラウザのwarning/errorなし。
- 決定論のテストで通常／記憶／終端の解放時刻、早押し無効、古い画面、鍵、確認ダイアログ、動き軽減を確認。`hazama-check`は2 PASS / 0 FAIL。
- 初見の人には攻略を伝えず、両方を読んで選べたか、解放までが「演出」か「待ち」かを聞く。身体の道で自分の選択が変化を生んだと思えた場面／思えなかった場面、浮上の意味と再降下意欲も聞く。販売品質の判定はまだしない。
