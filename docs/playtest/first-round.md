## 2. 見守り、終えてから聞く

道や「正解」は教えない。止めたい人を結末まで誘導しない。操作説明を求められた場合は助けてよいが、
何を補助したかを結果に添える。約15分は試遊の区切りで、クリア時間の約束ではない。

まず参加者用案内の3問だけを聞く。必要な場合だけ、次を追加する。

- 読みにくさ・待ち：全文表示や拡大を使った場所、その前後でどう変わったか。
- 結末：どのような終わり方だと受け取ったか。実施者が「成功／失敗」を先に名付けない。
- 英語：問題になった原文の一文と受け取った意味、声の違い、記憶の問いに納得できたか。
  詳細は[英語試作の確認項目](english-trial-e43.md)へ。
- 音や端末：本人が困った場合だけ、[実機/PWA手順](../autonomy/pwa-install-offline-checklist.md)や
  [taste pass](human-playtest-template.md)で再確認する。初見試遊と端末の再現テストを分ける。

## 3. 返答を修正につなぐ

返答は、本人が共有を了承した範囲でこの会話へ渡す。氏名・連絡先・生の録画・保存データは不要。
公開repoやSESSION-LEDGERには生の回答を貼らず、公開してよいと確認できた匿名要約だけを残す。
回答がない項目を「問題なし」で埋めず、未回答／未観察／未実施とする。

```text
種別：日本語自由試遊 / 英語身体ルート翻訳 / 端末再確認
匿名ID・日付・試したbuild：
初見 / 再訪、端末・ブラウザ、時間、読み方・音の設定：
本人の説明（了承範囲の要約）：
実際に観察できた行動（見ていなければ未観察）：
最後に止めた場所・理由：
説明を補った箇所：
再プレイ：実際に始めた / したいという回答 / したくないという回答 / 未確認
再現できる不具合と、好み・解釈を分けたメモ：
次に確認すること / 公開要約への了承：
```

受け取ったら、次の順に扱う。

1. 起動不能・押せない・読めない・記憶の消失などは、再現して優先修正する。感想とは別に追跡する。
2. 選択の意味・終わり・英語表現の混乱は該当箇所に戻り、説明を増やす前に何が伝わらなかったか確かめる。
3. 続ける理由が弱い場合は、場面と理由を見て次の小さな仮説を作る。一人の意見だけで全面改稿しない。
4. 好反応でも「販売品質」「売上見込み」「人間gate全通過」とはしない。
   発言した再プレイ意欲と、実際の再プレイ行動も同じものとして数えない。
