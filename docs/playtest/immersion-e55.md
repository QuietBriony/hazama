# E55 — 説明から気配へ、文字と景色を分ける

## 指摘と原因

2026-10-01のスマホ画像で、Ωの端末名、入口の八観一覧、文字に重なる赤線、
単調な背景、公開/PWAの版が分からない点が指摘された。

- 調査時のPages最新成功は`9dc2256`（9/28）、本編はE54。
  独立Three.jsの`5483024`と`244264d`はfeature branchだけにあり、未公開だった。
  添付のΩ本文は公開E54と一致する。画像だけでスマホのSW版は断定できない。
- E49は初回Aの八観だけを隠した。保存済みの周回では8名称がまとめて戻っていた。
- `.scrawl.cross`は本文中央にSVG線、降下択は下線、退路は取り消し線を重ねていた。
- 背景は累積沈下22で底の絵へ到達し、輝度0.14×不透明度0.36に落ちる。
  深い選択では物語の途中から同じ、ほぼ黒い絵になっていた。

## 修正と境界

入口は初回/周回とも感覚と選択に絞る。八観の一覧をAから撤去し、流れの道の
中盤で体験に名を付け、Sで八つがそろう。再訪Aは既存の訪問集計だけから、
身体の道なら足裏の冷たさ、構造の道なら月の継ぎ目を思い出す。

Ωは「薄明かりの向こうで、この行を読む私」を残し、端末名と物語/AI/読者の
説明列挙を外す。帰還は机の木目、戻る部屋の音、首の後ろの息で冒頭へつなぐ。
同じ周回変奏から旧文言が戻らないよう、変奏バンクと英語試作も同期した。
物語全部を改稿したものではない。

赤い線は本文/択に重ねず、左余白の痕跡へ。折り返す択も文字を打ち消さない。
背景は`data-backdrop`で物語の位置（入口/漂流/外殻/裏側/Ωの手前）へ進む。
既存4枚を再利用し、外殻の途中でcropを変える。深部の灯りを残し、本文の背面だけ
薄い暗幕にして可読性を分離。幾何の線は弱める。動きは有限の遷移、停止設定は維持。

設定に「表示中の版: E55」と、記憶を消さず入口へ戻る再読み込みを置いた。
CSS/JS/本文/英語/SWをE55へ同期。既存のnetwork-first HTMLとSW引継ぎを利用し、
キャッシュ一括消去やストレージの移行は追加しない。

本編は静的Web/既存canvas/CSSのまま。Three.jsは[駅の独立比較](../../tools/visual/station-window-three-lab.html)
だけで使う。固定CDN例外を本編へ広げず、3D化したと誤認させない。
数値、分岐グラフ、storage key/schema、保存項目、音は変えない。
