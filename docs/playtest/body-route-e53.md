# E53候補 — 身体の道の選択を読める言葉にする

2026-09-27。E52の「全候補を見てから選ぶ」を土台にした改稿。E53として公開。人間の好みや販売品質を確認した結果ではない。

## 試遊からの仮説

身体の道はB→D→F→J→N→S→V→Y→Zと進めるが、軽い選択の副文が「沈む」「それでも沈む」に寄っていた。二択は同じ次ノードへ進む一方、深く受けとめる側は認識が増えて戻り道を1本閉じ、もう一方は戻り道を減らさない。結果が異なるのに、選ぶ前の言葉からは読み取りにくかった。

また、Bの深度の説明とNの「数字だけのゲームじゃない」は、場面から離れて説明に聞こえる可能性がある。断定的な感想ではなく、改稿して初見の人に比べてもらう仮説とする。

## 変更

- Bでは床板と胸が同時に沈む出来事へ、Nでは署名した紙から知らない誰かの息づかいと熱が伝わる場面へ変更。説明だけでなく、身体で起きる異変を残す。
- 身体の道の8つの軽い選択は、それぞれの場面に沿った短い副文と「戻り道は減らない」を表示する。残数が0でも正しい表現にした。重い選択の代償「戻り道 −1」は従来どおり。
- 同じ日本語キーの英語試作も同期。戻り道0本では、重い選択の「−1」を「戻り道は尽きた」（英語は `No ways back remain`）に表示だけ切り替える。選択肢の数、行き先、`deep`、認識・沈下・圧・戻り道の値、保存形式、音は変えない。
