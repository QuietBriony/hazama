# E54候補 — 構造の道の冒頭で、選ぶ前に代償を読めるか

2026-09-27。公開E53を構造の道へ初回降下した試遊からのローカル候補。人間の好みや販売品質を確認した結果ではない。公開ページはE53のまま。

## 試遊で確認した問題

零章→A→構造B→C→Dを390pxの独立ブラウザで読むと、深く読む側は「戻り道 −1」を予告する一方、同じ次の場面へ進む軽い択の副文は「それでも沈む」「沈む」だけだった。BとCの軽い択を選んでも、戻り道4本・認識1/6は維持された。実際の差が、選ぶ前には読みにくい。

また、Cの「引き返す」は退路が0本でも固定文の「まだ浅い。戻れる（戻り道 −1）」を表示し得る。実際は戻り道を消費せず、沈下が増す。表示の約束と結果を合わせる必要がある。

320pxで実際に退路0本まで通すと、この押せるCの退路が`opacity: 0.55`、主文は暗い文字、副文はさらに暗い文字で、封印された択のように見えた。文字を読んで選ぶ機会そのものを弱める。

## 変更した範囲

- B/C/Dの軽い択だけ、月の継ぎ目・開かない記憶・書換え表示に沿った短い副文へ変更し、「戻り道は減らない」を表示。Bの主文も月の場面に合わせた。
- 周回後に選ばれるB/Dの言い換えも同じ費用を示す。Cの退路が0本のときだけ、周回の言い換えより優先して「引き返そうとする／戻っても沈下は深まる」と表示。
- 押せる「重い退路」は透明度を下げず、通常の明るさの文字を使う。重さは打ち消し線と点線枠で表し、ロックされた択とは見分けられるままにする。
- 行き先、択の数、`deep`、認識・沈下・圧・戻り道の値、保存、音、英語試作の対象は変えない。
